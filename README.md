What is ErrorMind?
ERRORMIND 2.0 is a browser-based Alternate Reality Game (ARG) — a psychological puzzle experience built entirely as a single HTML file. No installation. No server. Just open it in a browser and go.
The game challenges players through 19 layered levels, each requiring a completely different skill — logic, cryptography, pattern recognition, memory, and psychological resilience.
The deeper you go, the more you realize:

The system is not testing your intelligence. It is testing your identity.
